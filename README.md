# LandingCraft - SaaS Landing Page

A modern, responsive landing page for **LandingCraft**, a SaaS application that helps users create stunning landing pages quickly and efficiently.

## 🚀 Features

- **Modern Design**: Clean, professional design with beautiful gradients and animations
- **Fully Responsive**: Optimized for all devices from mobile to desktop
- **Interactive Elements**: Smooth scrolling, hover effects, and micro-interactions
- **Performance Optimized**: Fast loading with optimized assets and code
- **SEO Ready**: Proper meta tags and semantic HTML structure
- **Cross-browser Compatible**: Works on all modern browsers

## 📱 Sections Included

1. **Navigation**: Sticky header with smooth scroll navigation
2. **Hero Section**: Compelling headline with CTA buttons and social proof
3. **Features**: Showcase of key product features with icons
4. **Pricing**: Three-tier pricing table with highlighted popular plan
5. **Testimonials**: Customer reviews and social proof
6. **CTA Section**: Final call-to-action to convert visitors
7. **Footer**: Contact info and additional links

## 🛠 Technologies Used

- **HTML5**: Semantic markup and accessibility features
- **CSS3**: Modern styling with Flexbox, Grid, and animations
- **Vanilla JavaScript**: Interactive functionality and animations
- **Google Fonts**: Inter font family for clean typography
- **No Framework Dependencies**: Pure web technologies for fast loading

## 🚀 Quick Start

### Prerequisites
- Node.js (for development server)
- A modern web browser

### Installation

1. **Clone or download** this repository:
```bash
git clone https://github.com/yourusername/landingcraft-landing.git
cd landingcraft-landing
```

2. **Install dependencies** (optional - for development tools):
```bash
npm install
```

3. **Start development server**:
```bash
npm run dev
```
Or simply open `index.html` in your browser.

### Available Scripts

- `npm start` - Start HTTP server on port 3000
- `npm run dev` - Start live-reload development server
- `npm run serve` - Serve on port 8080
- `npm run validate` - Validate HTML markup
- `npm run optimize` - Optimize images (if you add any)
